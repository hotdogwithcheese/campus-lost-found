# campus-lost-found

A Flutter app to help students post and find lost items on campus.

Web Version
- Hosted on Netlify:
- https://campuslost-found.netlify.app/

## Feature
- Post lost/found items with images

## App Functions
- Filter items by status (Lost, Found, Claimed)
- Categorize items (Electronics, Bags, Books, Clothing, Accessories, Others)
- View item details including description, category, status, and images
- Staff mode to claim/unclaim or delete items
- Offline mode to view cached items when internet is unavailable
- Search and sort items efficiently
- Refresh the feed to load the latest items
