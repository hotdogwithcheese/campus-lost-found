# Campus Lost & Found App – Installation Guide

Follow these steps to install the app on your Android device:

## 1. Download the APK
[Click here to download the APK](https://drive.google.com/file/d/1eecPGJdPp1mfEFrXH09A-ukmJiirzBV6/view?usp=drive_link)

## 2. Enable Installation from Unknown Sources
- **Android 8.0+**: The installer will request permission automatically.
- **Older versions**: Go to Settings > Security > Unknown Sources and enable it.

## 3. Install the App
Open the downloaded APK, tap **Install**, and wait for installation to finish.

## 4. Launch the App
Open the app from your home screen or app drawer.

## Notes

- Make sure your device has enough storage space for the app.
- Only download APKs from trusted sources to avoid security risks.
- Staff access requires a PIN (default: `1234`) to mark items as claimed or delete items.
